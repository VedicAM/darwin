# Darwin three-minute demo

Use only numbers visible in the live panel or generated reports. If a value says
`not measured`, say that plainly and show the mechanism instead.

## Preflight

Sixty seconds before presenting:

```bash
python -m evolution.smoke_test --live-model
```

Keep `python -m evolution.live_panel` open with a read-only Atlas database user.
Keep `python -m evolution.live_panel --replay evolution/runs/toc_evolution_log.json`
ready as the network-independent fallback. Rehearse once without Wi-Fi.

## Run of show

### 0:00–0:20 — Impact

“Teams hand-organize agent tools, but almost nobody measures whether that
organization routes work correctly. A wrong route costs the token and latency
delta shown here before the agent even starts the real task. Darwin turns the
tool catalog into an evaluated, self-improving system.”

Point to the recorded wrong-versus-right cost from `transfer_test.py`.

### 0:20–0:50 — Live system

Point to `live_panel.py`:

- lineage and rejected children;
- mutation documents arriving from Atlas;
- held-out test R@1 versus the flat reference;
- plain-language promoted discoveries.

Say: “This is polling Atlas now. The same UI replays the signed run log if venue
Wi-Fi disappears, and the banner makes that state explicit.”

### 0:50–1:40 — Creativity

Run `python -m evolution.phylogeny`. Choose one leaf with more than one fossil
event. Follow it from human creation through rewrite/split/move and any rejected
or pruned descendant.

Say: “The taxonomy is a living document with a fossil record. Every change has a
parent, diagnosis, selection result, and survival status.”

### 1:40–2:20 — Difficulty

Show `RIGOR.md`, generated by:

```bash
python -m evolution.rigor_report --verify-routing
```

Point only to the three split boundary, exact binomial promotion rule, guard
rejection counts, paired bootstrap knockouts, verified structural hashes, and
the duplicate temperature-zero route vector.

### 2:20–2:45 — Transfer

Run `python -m evolution.transfer_test`. Say whether the evolved taxonomy wins,
ties, or loses on leaves that no promoted mutation touched. A loss is a measured
limit of local optimization, not a failed demo.

### 2:45–3:00 — Close

Open Atlas Data Explorer on `darwin_evaluation`. Show the existing 49-node Darwin
evaluation tree, the Negative Results Registry, the Paper2Code evidence gate,
and the evolution collections.

“Biology gives us checkable answers, but this loop applies to any agent with more
tools than a person can reliably hand-tune.”

## Roles

The keyboard driver and narrator should be different people. Cut any transition
that pushes the rehearsal beyond 3:00; do not accelerate the final thirty seconds.
